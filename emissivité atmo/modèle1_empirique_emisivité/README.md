* [calcul_section_efficace_CO2_CH4_H2O.py](calcul_section_efficace_CO2_CH4_H2O.py): Le script Python qui calcule et trace les spectres d'absorption (sections efficaces) du CO<sub>2</sub> du CH<sub>4</sub>  et de l'H<sub>2</sub>O en fonction de la longueur d'onde.
* [code1_emissivité_une_couche.py](code1_emissivité_une_couche.py):Le script Python de base qui calcule l'épaisseur optique et l'émissivité d'une seule tranche d'air en fonction de sa pression, de sa température et de sa concentration en CO<sub>2</sub>
* [Documentation_emissivite_code_1.pdf](Documentation_emissivite_code_1.pdf) : La documentation qui explique la démarche et le code 1 avec une seule couche
* [code2_emissivité_n_couche.py](code2_emissivité_n_couche.py):Le script Python qui calcule l'épaisseur optique globale et l'émissivité totale d'une couche d'air en cumulant l'impact simultané de plusieurs gaz à effet de serre (CO<sub>2</sub>,CH<sub>4</sub>  et H<sub>2</sub>O).
* [code3_emissivite_avec_concentrations.py](code3_emissivite_avec_concentrations.py)= Le script Python qui calcule l'émissivité d'une couche atmosphérique en récupérant dynamiquement les concentrations réelles de gaz (CO<sub>2</sub>, CH<sub>4</sub> et H<sub>2</sub>O) en fonction de son altitude.
* [code_H20_CH4_CO2_O3.py](code_H20_CH4_CO2_O3.py): Le script Python de base qui définit le profil thermique vertical de l'atmosphère et modélise la répartition des concentrations de gaz à effet de serre (CO<sub>2</sub>,CH<sub>4</sub>  et H<sub>2</sub>O) selon l'altitude.
