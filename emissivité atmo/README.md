* [calcul_section_efficace_CO2_CH4_H2O.py](calcul_section_efficace_CO2_CH4_H2O.py)= Le script Python qui calcule et trace les spectres d'absorption (sections efficaces) du $CO_2$ du $CH_4 et de l'H$_2$O en fonction de la longueur d'onde.
* [code1_emissivité_une_couche.py](code1_emissivité_une_couche.py)=Le script Python de base qui calcule l'épaisseur optique et l'émissivité d'une seule tranche d'air en fonction de sa pression, de sa température et de sa concentration en $CO_2$
* [code2_emissivité_n_couche.py](code2_emissivité_n_couche.py)= Le script Python qui calcule l'épaisseur optique globale et l'émissivité totale d'une couche d'air en cumulant l'impact simultané de plusieurs gaz à effet de serre ($CO_2$,$CH_4$ et $H_2O$).
* [code3_emissivite_avec_concentrations.py](code3_emissivite_avec_concentrations.py)= Le script Python qui calcule l'émissivité d'une couche atmosphérique en récupérant dynamiquement les concentrations réelles de gaz ($CO_2$, $CH_4$ et $H_2O$) en fonction de son altitude.
* [code_H20_CH4_CO2_O3.py](code_H20_CH4_CO2_O3.py)= Le script Python de base qui définit le profil thermique vertical de l'atmosphère et modélise la répartition des concentrations de gaz à effet de serre ($CO_2$,$CH_4$ et $H_2O$) selon l'altitude.
